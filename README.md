## Run it

```sh
node main.ts
```

`main.ts` checks the word against the gate (1–30 characters, one token, no whitespace) and writes it, and nothing else, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output/entry.txt` in the grader's sandbox).
